# IT & Field Support Playbook

Templates and checklists for running technical support for a fleet of connected devices (kiosks, smart coolers, IoT hardware) with third-party field technicians.

These came from building a support operation from scratch: moving service calls out of a spreadsheet into a ticketing system, writing procedures the field team could follow, and getting vendors, engineers and clients working from the same process. Everything here is generic and free to adapt.

## Principles

1. **One ticket per issue, one place for every ticket.** If it isn't in the ticket, it didn't happen.
2. **Troubleshoot remotely before you dispatch.** A truck roll costs money and a day; a reboot costs a minute.
3. **Escalate with full context.** Symptoms, timeline, what you tried, logs. Nobody should have to ask twice.
4. **Close the loop.** Every closed ticket has a root cause and the parts replaced, so patterns show up.
5. **Document as you go.** Every repeat issue becomes a knowledge base article.
